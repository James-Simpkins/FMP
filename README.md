<h1>World Helpers</h1>
<p><b>World Helpers</b> is a video game I created using Unity 6 as part of my Final Major Project for my first year of Technical Computing Level 3. The core idea is to raise awareness and teach players about environmental issues through minigames.</p>

<p>As this was a final project for the Technical Computing (Year 1) course around February - May, it was also around the time of GCSE Exams, which I had put revising for at much higher priority, which inadvertently meant that I didn't work on the game much and it only ended up teaching about a single environmental issue and had a minigame to go with it.</p>

<p>I also put a heavy amount of time into research for my Final Major Project rather than focussing mainly on my practical. Speaking of research, you can find it and all other parts of my Year 1 Final Major Project on my website I created for it using Wix at: https://s3017235.wixsite.com/tc-level3-fmp.</p>

<h2>Want to play?</h2>
<p>I haven't yet built the game from Unity, but I'll likely build as WebGL and host on Itch.io so that you don't need to download it. The reason I'm not yet providing a built version of the game is because I used Unity Editor 6000.0.38f1, which has a publically known vulnerability that affects built projects, you can read about it at: https://unity.com/security/sept-2025-01. I take no responsibility for any damages (including malware and data loss) if you decide to clone this repository and build the game in a vulnerable version of Unity Editor.</p>

<p>At some point, I will playtest in a newer version of the Unity Editor and if my game works properly, then I'll build and upload it to Itch.io after updating this repository.</p>
